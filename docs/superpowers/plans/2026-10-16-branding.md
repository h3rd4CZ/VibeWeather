# Vibe Weather Branding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace every visible .NET MAUI default with the Vibe Weather brand (design 1b "Orb"): app icon and themed icon, system and in-app splash, notification icons and colours, display name, template leftovers and the Blazor error bar.

**Architecture:** All Android artwork is authored as SVG and rendered to density PNGs by MAUI's resizetizer (`MauiIcon`, `MauiSplashScreen`, `MauiImage`). A few Android resource files wire in what MAUI can't do itself: the themed-icon layer, a splash theme with a night variant, and per-kind notification colours. One extension method gives each notification its icon, colour and picture. The animated splash is an HTML/CSS overlay in `index.html`; a small Razor component hands over to the app after the first render.

**Tech Stack:** .NET 10 MAUI Blazor Hybrid (Android only, min API 24), MAUI Resizetizer 10.0.110 (Svg.Skia), AndroidX NotificationCompat, CSS animations.

**Spec:** `docs/superpowers/specs/2026-10-16-branding-design.md`

**Conventions (read first):**
- App root: `C:\dev\misc\scratchpad\mauiapp\VibeWeather`. Paths below are relative to it, unless they start with `docs/` or `doc/`, which are relative to `C:\dev\misc\scratchpad\mauiapp`.
- User-visible text is Czech. Comments stay English, short and explanatory, matching the existing code.
- **Build:** `dotnet build C:\dev\misc\scratchpad\mauiapp\VibeWeather -f net10.0-android -c Debug` should print `Počet chyb: 0` ("chyb" is Czech for errors).
- **Emulator deploy** (from the app root): `dotnet build -t:Run -f net10.0-android -c Debug -p:AdbTarget="-s emulator-5554" -p:RuntimeIdentifier=android-x64`. Never use `EmbedAssembliesIntoApk`. Never deploy to a physical phone.
- **adb:** `"$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe"`, which isn't on PATH. Below it's written as `adb`.
- **Resizetizer limits** (tested 2026-10-16): `<mask>`, `<linearGradient>`, `fill-rule="evenodd"` and transforms work. **SVG `<filter>` crashes the build (MAUIR0001), so never use filters.** An SVG's `width`/`height` is its size in dp.
- **Generated PNGs** land in `obj/Debug/net10.0-android/resizetizer/r/drawable-xxxhdpi/` (images) and `.../mipmap-xxxhdpi/` (app icon). Open them with an image viewer, or the Read tool, to check the art.
- The folder is not a git repository, so there are no commit steps. Files are UTF-8; keep the existing line endings.

```razor
@* The start screen in index.html hands over to the app here: after the first render it fades out, and the
   appearance is remembered so the next start's splash is drawn light or dark to match. *@
@implements IDisposable
@inject ThemeService Theme
@inject IJSRuntime JS

@code {
    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (!firstRender) return;
        Theme.Changed += OnThemeChanged;
        await SaveTheme();
        await JS.InvokeVoidAsync("vibeWeather.splashDone");
    }

    void OnThemeChanged() => _ = InvokeAsync(SaveTheme);

    Task SaveTheme() => JS.InvokeVoidAsync("vibeWeather.saveTheme", Theme.Mode.ToString().ToLowerInvariant()).AsTask();

    public void Dispose() => Theme.Changed -= OnThemeChanged;
}
```
